# Vedant P. — Interactive Portfolio

A high-end, cinematic, and motion-driven personal portfolio designed to showcase a unique blend of **Web Development** and **Cybersecurity** expertise. 

This project prioritizes **Interaction Design** and **Visual Excellence**, utilizing industry-standard animation libraries to create a "living" web experience.

## ✨ Key Features

- **Cinematic Motion System**: A custom-built animation engine powered by **GSAP**, featuring staggered word reveals, masked line transitions, and deep parallax effects.
- **3D Orbital Skills System**: An interactive, mouse-reactive 3D orbit showcasing core competencies with autonomous text-switching logic.
- **Smooth Interaction (Lenis)**: Integrated **Lenis Smooth Scroll** for a fluid, tactile navigation experience across all sections.
- **Ultra-Deep Project Reveals**: Projects feature "fly-away" zoom-out animations and progressive text staggers, ensuring a premium "Work" showcase.
- **Identity-Driven About Section**: A minimalist, structured supporting layer that balances bold typography with personal "Core Focus" and "Currently Exploring" blocks.
- **Interactive Contact Physics**: A high-response contact CTA with magnetic hover logic, expansion effects, and micro-interactions.

## 🛠️ Tech Stack

- **Framework**: [Vite](https://vitejs.dev/) (Lightning fast development and bundling)
- **Animations**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger, Timelines)
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Styling**: Vanilla CSS (Custom properties, Flexbox/Grid, Glassmorphism)
- **Typography**: Outfit & Playfair Display (via Google Fonts)

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vedsp/Portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run in development mode**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🎨 Design Philosophy

The site follows an **Awwwards-inspired aesthetic**:
- **Dark Minimalist Theme**: Deep blacks (`#0a0a0a`) contrasted with high-vibrancy accents (`#c5fb45`).
- **Texture Layer**: A global noise/grain overlay for a premium, analog feel.
- **Hierarchy**: Strong focus on typography scale and intentional whitespace.
- **Micro-Interactions**: Magnetic effects and underline slides to ensure no element feels inert.
